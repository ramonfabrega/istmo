# Waveform provenance

`BW.BGLD.mseed` is the original public ObsPy example, downloaded from https://examples.obspy.org/BW.BGLD..EH.D.2010.037 on 2026-10-09 (Panama date). It contains recorded German BW.BGLD channels dated 2010-02-06. It is NOT a Panama recording.

`replay.mseed` is generated by `scripts/prepare-fixtures.ts` using seisplotjs to decode the original, then repacking EHZ samples into approximately one-second uncompressed miniSEED 2 records. Sample values and original timestamps are preserved; station display location and replay timeline are explicitly synthetic. Original records remain available for comparison. Source example: https://docs.obspy.org/tutorial/code_snippets/reading_seismograms.html . ObsPy code is LGPL-3.0; this public example is retained for local development. Confirm waveform redistribution permissions before public distribution.

`up.html` is a captured public table for parser regression tests; live collection always fetches a new page. It is never silently substituted for a live feed.

Map geometry in `public/land.json` comes from world-atlas/Natural Earth (public-domain cartography). No API key or remote tile service is needed for the initial country-level globe. This is not a street map.
